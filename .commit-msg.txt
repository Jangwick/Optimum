fix: remove required attr from hidden file input that blocked upload

The hidden file input in DocumentsTab had a `required` attribute.
When a file input is hidden, some browsers silently fail form
validation because they cannot display the validation message for
a hidden element. This caused the Upload button to appear to do
nothing when clicked, even when a file was selected.

The `required` attribute was redundant because:
1. The Upload button is already disabled when no file is selected
   (`disabled={uploading || !file || !categoryId}`)
2. The handleUpload function already checks `if (!file || !categoryId)
   return;`

Removed the `required` attribute from the hidden file input.

1. Selected file via dropzone → file card shown with name and size
2. Selected category "Policy" → Upload button enabled
3. Clicked Upload → document persisted to backend
4. Total Documents increased from 1 to 2
5. New document "test-upload.txt" appears in Policy category
6. Form reset to empty state after upload
7. No JS errors
