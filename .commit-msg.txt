switch between active, closed, and cancelled claims without using the
process status dropdown.

- Each tab has an icon (ClipboardList, Lock, Ban)
- Active tab highlighted with primary background
- View param sent to API in both list and export requests
- Clear filters button resets view to Active
- Switching tabs resets to page 1

  - closed: where.isReadOnly = true, where.isCancelled = false
