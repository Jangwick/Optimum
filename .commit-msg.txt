fix: repair ClaimInvestigation inspections and photo upload

The Investigation tab's Inspections sub-tab had multiple bugs:

1. "Invalid Date" — frontend used `i.scheduledDate` but the schema field
   is `scheduledAt`. Fixed all field references to match the Prisma schema.

2. Empty status span — the Inspection model has no `status` field. The
   frontend tried to render `i.status` which was always undefined. Now
   uses `conductedAt` as the completion indicator: if `conductedAt` is
   set, the inspection is "Completed"; otherwise "Scheduled".

3. "Complete" button not working — `completeInspection` sent
   `{ status: 'COMPLETED', completedAt: new Date() }` but the backend
   passed these directly to Prisma, which rejected the unknown fields.
   Now sends `{ findings, conductedAt }` which are valid schema fields.
   Also fixed `updateInspection` to only send known fields instead of
   spreading all data blindly.

4. Photo upload not working — used raw `fetch()` without auth headers and
   posted to the documents endpoint instead of an inspection-specific
   endpoint. Added:
   - Backend: `POST /api/claims/:claimId/inspections/:id/photos` route
     with Multer upload, `uploadInspectionPhoto` controller, and
     `uploadPhoto` service that creates `InspectionPhoto` records
   - Frontend: `uploadInspectionPhoto` service function using the api
     client with proper auth
   - Upload button is now disabled until a file is selected
   - File input accepts images only (`accept="image/*"`)
   - File input resets after upload

5. Visual improvements:
   - Sub-tabs now have icons (Search, Users, Calendar)
   - All forms have labeled fields with focus rings
   - Inspection cards show location with MapPin icon
   - Status pills use design-system colors (success/accent-orange)
   - Completed inspections show findings section with timestamp
   - Photos display in a responsive grid with Camera icon
   - All containers use rounded-lg consistently

Backend `listInspections` now includes photos and inspector relation.
`createInspection` and `updateInspection` also return photos.
